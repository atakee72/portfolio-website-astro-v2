# Getting Started with Astro

Astro is a modern static site builder that delivers lightning-fast performance with a powerful developer experience.

## Why Astro?

- **Zero JS by default**: Ship only the JavaScript you need
- **Component Islands**: Mix and match frameworks
- **Fast builds**: Optimized build process

## Key Features

Astro brings together the best parts of modern web development:

1. Server-first rendering
2. Content collections with type safety
3. Built-in optimizations

```typescript
// Example Astro component
---
const greeting = "Hello, Astro!";
---

<h1>{greeting}</h1>
```
