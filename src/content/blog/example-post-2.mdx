# TypeScript Best Practices

TypeScript has become an essential tool for building robust applications. Here are some best practices to follow.

## Type Safety Matters

Always prefer explicit types over implicit any:

```typescript
// Good
function greet(name: string): string {
  return `Hello, ${name}!`;
}

// Avoid
function greet(name: any) {
  return `Hello, ${name}!`;
}
```

## Use Zod for Runtime Validation

Combine TypeScript with Zod for both compile-time and runtime safety.
