## Problem

The Schillerkiez (Berlin Neukölln) needed a digital commons — forum,
calendar, marketplace, local news, air-quality data — without surrendering
to a global platform.

## Build

Astro SSR + React + Svelte islands, MongoDB direct driver, auth-astro
with JWT, TanStack Query with 24h localStorage persistence, Motion for
animation, Resend for transactional email, Sentry for observability.
Forum, calendar, marketplace, newsboard with daily fetch, recommendations,
reports & admin moderation — plus a full MDX blog ("Die Beilage") and a
profile & account-lifecycle system: a Meldebogen with a Kiez-Chronik
tenure timeline, a printable QR-coded Steckbrief card, public neighbor
profiles, and a 7-day-undo account deletion that anonymizes into an
"Ehemaliges Mitglied" tombstone while preserving authored content.

Since then the app grew a built-in onboarding walkthrough, Die
Führung (seven chapters, 32 stops), a shared mailer that fails closed
with a 503 instead of dropping a message silently, site search,
DeepL translation of posts, server-side drafts, and `@handle`
identities with mentions. The front door changed twice. In August the
forum moved to `/forum` behind a login gate and the root became Das
Schaufenster, a public shop window; in September a visitor said it
"looks so serious it looks like a political website", and the wall of
type became six phone-shaped frames, one per section, each drawn live
from today's content in its own colour, in a strip that scrolls
sideways by itself and by hand. The frames never render a member's
name, handle or avatar — stricter than the sections themselves — and
a frame with nothing live falls back to a static screenshot or is
omitted, never shown empty. Members are redirected before render and
never see it.

## Architecture

Multilingual AI moderation (TR/EN/DE + leetspeak filters) gates all
user content, backed by a 3-strike ban system that drops banned
sessions to read-only. The kiosk redesign — paper-warm surfaces, ink
borders, carved-italic titles — is complete across all eleven
surfaces, landing to blog. BLUME air-quality readings and Schillerkiez
demographics still come from public APIs, and the marketplace runs a
13-category taxonomy with draft/publish, a 21-day visibility window,
and buyer↔seller contact relayed so neither side sees an email
address — the buyer's is stored only as a salted hash with a 90-day
TTL.

The notification center exists because members learned about replies
by stumbling over them, and about moderation decisions not at all — a
post simply disappeared. Six events now fan out on write into a
`notifications` collection: comments, every moderation decision
including clean approvals and the strike number, official broadcasts,
marketplace inquiries, `@mentions`, and an admin-only `@alle` that
reaches members active in the last 90 days. Actor names are never
stored, only ids joined at read time, so a deleted account reads
"Ehemaliges Mitglied" retroactively. A Mongo TTL index expires
everything after 90 days; the bell polls an indexed count every 90
seconds while the tab is visible — no held-open connections on
serverless for neighbourhood volume — and web push rides on top as
best-effort garnish.

Handles arrived from one question — is there a uniqueness check on
names? There wasn't; two members already shared one. Names may repeat,
the handle is the identity, and a mention is resolved when the text is
saved and stored by member id, so a later rename can't redirect it.
Researching that surfaced a data-exposure bug: about a dozen routes
joined a user record with "everything except the password", so a
comment list carried its author's email. One shared allowlist now.
The pure modules carry 41 test files.

## Reflection

Built with a manifesto attached — `MANIFESTO.md` sits at the repo's
root as its moral charter, paired with a PolyForm Noncommercial
license and a Field-of-Use Rider: open to nonprofits and public
institutions, closed to political parties, for-profit deployment,
resident surveillance, resale — and to a single person running a copy
as both deployer and sole moderator.

Neither of this year's worst failures announced itself. OpenAI's
credits ran out: the news cron kept returning 200 while saving
nothing, and every submission needing moderation got waved into the
manual review queue — four days with no monitoring event, because both
paths were caught, logged and handled gracefully. Then the domain move
killed a GitHub Actions cron that rang the air-quality logger every
half hour — two days of writing nothing, recorded nowhere, because a
redirect is served at the edge and no application code ever runs. A
cron that returns 200 is not a cron that worked.

The security audits had a blind spot of their own: they followed the
UI. The login gate's `?redirect=` guard checked characters, reviewed
twice — but the URL parser normalises before it resolves, so a crafted
path passed every check and landed off-site; the fix parses against a
fixed base origin and returns the parsed path. And a link-preview
endpoint no screen had called since June was still reachable by any
member and still fetched whatever it was handed — every click-through
audit walked straight past it. An endpoint nobody calls is still an
endpoint.

The platform launched for real in September: two Saturdays at an info
stand on the Schillermarkt, a table, flyers in four languages, a
tablet. Readiness was sized to the room, not the cloud — the stand's
hotspot is one IP, so the signup limit went from 5 to 40 an hour with
a per-email brake; Resend's free tier pauses all sending at a 4% bounce
rate, which two typos in fifty signups would hit; Atlas throttles at
100 ops/s without an error. Writing the failure runbook row by row
found the launch-blocker no audit had: an OpenAI outage would have
refused every signup as "inappropriate name", because the moderation
helper returns a fail-safe verdict instead of throwing and the name
check read it as a no — the code did the opposite of its comment. The
first stand day logged zero errors; two weeks after launch the Kiez
had around fifty registered neighbours.
