## Problem

The Schillerkiez (Berlin Neukölln) needed a digital commons — forum,
calendar, marketplace, local news, air-quality data — without surrendering
to a global platform.

## Build

Astro SSR with Svelte islands (React survives only in two dialogs and
the e-mail templates), MongoDB direct driver, auth-astro with JWT,
TanStack Query, Resend for e-mail, Sentry for observability.
Forum, calendar, marketplace, newsboard with daily fetch, recommendations,
reports & admin moderation — plus an MDX blog ("Die Beilage"), public
neighbour profiles with a printable QR-coded Steckbrief, and a
7-day-undo account deletion that anonymizes into an "Ehemaliges
Mitglied" tombstone while preserving authored content.

Since then: Die Führung, an onboarding walkthrough (seven chapters,
32 stops), a shared mailer that fails closed with a 503, site search,
DeepL translation of posts, drafts, and `@handle` identities with
mentions. The front door changed twice. In August the
forum moved to `/forum` behind a login gate and the root became Das
Schaufenster, a public shop window; in September a visitor said it
"looks so serious it looks like a political website", and the wall of
type became six phone-shaped frames, one per section, each drawn live
from today's content in its own colour. The frames never render a
member's name, handle or avatar, and a frame with nothing live falls
back to a static screenshot or is omitted, never shown empty.

October added the Kiez-Brief, a weekly members' mail built from the
week's public content, and personal invitation links. Every eligible
member — confirmed address, seven days in — holds one permanent link
with a QR code, good for five new neighbours per rolling thirty days.
Permanent because a printed card must not expire; the cap throttles
instead. Mahalle never sends the invitation itself, since in Germany a
tell-a-friend mail from a platform counts as unsolicited advertising,
so members share it from their own phone and the platform never sees
the recipient's address. A dead link says so and still lets you
register. A lookup that stalls past 2.5 seconds keeps the code in the
form and lets the server decide on submit — the first version fell
back to a plain form with no notice, which quietly dropped the inviter
on every slow cold start.

## Architecture

Multilingual AI moderation (TR/EN/DE + leetspeak filters) gates all
user content, backed by a 3-strike ban system that drops banned
sessions to read-only, deletes included. The kiosk redesign is
complete across all eleven surfaces. BLUME air-quality readings and Schillerkiez
demographics still come from public APIs, and the marketplace runs a
13-category taxonomy with draft/publish, a 21-day visibility window,
and buyer↔seller contact relayed so neither side sees an email
address — the buyer's is stored only as a salted hash with a 90-day
TTL.

The notification center exists because members learned about replies
by stumbling over them, and about moderation decisions not at all — a
post simply disappeared. Nine events now fan out on write into a
`notifications` collection: comments, every moderation decision
including clean approvals and the strike number, official broadcasts,
marketplace inquiries, `@mentions`, new blog and forum posts, moved
events, and an admin-only `@alle` that reaches members active in the
last 90 days. Actor names are never stored, only ids joined at read
time, so a deleted account reads "Ehemaliges Mitglied" retroactively.
A TTL index expires everything after 90 days; the bell polls a count
every 90 seconds while the tab is visible, and web push rides on top
as best-effort garnish. When an author changes an event's date or
place, everyone who answered or saved it gets a bell row — always; a
flood brake silences only the push, because a brake that drops the
message makes the app lie. A longer end time is not a move, even when
it crosses midnight.

The Kiez-Brief is shaped by a free mail tier of 100 mails per UTC
day. An issue goes out in groups of 75, one per day, each group
claimed in the database with a conditional update before a single
mail is sent, so two runs can't send it twice and a process that dies
between claim and send leaves a visible gap. Two hours before the members' mail the admin gets a
test copy and a Telegram line. "View in browser" stores no snapshot:
the issue is rebuilt from today's data for its week, so deleted posts
and anonymised names vanish from old issues for free. The first issue
reached 59 members on 4 October.

Handles arrived from one question — is there a uniqueness check on
names? There wasn't; two members already shared one. Names may repeat,
the handle is the identity, and a mention is resolved when the text is
saved and stored by member id, so a later rename can't redirect it.
Researching that surfaced a data-exposure bug: about a dozen routes
joined a user record with "everything except the password", so a
comment list carried its author's email. One shared allowlist now.
The pure modules carry 64 test files.

## Reflection

Built with a manifesto attached — `MANIFESTO.md` sits at the repo's
root as its moral charter, paired with a PolyForm Noncommercial
license and a Field-of-Use Rider: open to nonprofits and public
institutions, closed to political parties, for-profit deployment,
resident surveillance, resale — and to a single person running a copy
as both deployer and sole moderator.

Neither of this year's worst failures announced itself. OpenAI's
credits ran out: the news cron kept returning 200 while saving
nothing, and every submission needing moderation got waved into the
manual review queue — four days unnoticed, because both paths were
caught, logged and handled gracefully. Then the domain move killed a
GitHub Actions cron for the air-quality logger — two days of writing
nothing, because a redirect is served at the edge and no application
code ever runs. A cron that returns 200 is not a cron that worked.

In October Vercel reported three quarters of the month's free CPU
gone by day eleven, at roughly two thousand requests a day. A local
production build told a different story: a warm request costs 5–40 ms,
but the first request on a fresh instance cost 1.2–2.9 s, because Node
resolved and compiled about a thousand small files — Sentry and
OpenTelemetry, a date-fns barrel import, the auth library. Bundling
them into the server chunks brought the landing's cold start to
0.43 s, measured locally. The bill was cold starts, not traffic.

The security audits had a blind spot of their own: they followed the
UI. The login gate's `?redirect=` guard checked characters — but the
URL parser normalises before it resolves, so a crafted path passed
every check and landed off-site; the fix parses against a fixed base
origin and returns the parsed path. And a link-preview endpoint no
screen had called since June was still reachable by any member and
still fetched whatever it was handed. An endpoint nobody calls is
still an endpoint.

The platform launched for real in September: two Saturdays at an info
stand on the Schillermarkt. Readiness was sized to the room, not the
cloud — the stand's
hotspot is one IP, so the signup limit went from 5 to 40 an hour with
a per-email brake; Resend's free tier pauses all sending at a 4% bounce
rate; Atlas throttles at 100 ops/s without an error. Writing the failure runbook row by row
found the launch-blocker no audit had: an OpenAI outage would have
refused every signup as "inappropriate name", because the moderation
helper returns a fail-safe verdict and the name check read it as a
no — the code did the opposite of its comment. The
first stand day logged zero errors; by early October the Kiez had
sixty-two registered members.
