## Problem

The Schillerkiez (Berlin Neukölln) needed a digital commons — forum,
calendar, marketplace, local news, air-quality data — without surrendering
to a global platform.

## Build

Astro SSR + React + Svelte islands, MongoDB direct driver, auth-astro
with JWT, TanStack Query with 24h localStorage persistence, Motion for
animation, Resend for transactional email, Sentry for observability.
Forum, calendar, marketplace, newsboard with daily fetch, recommendations,
reports & admin moderation — plus a full MDX blog ("Die Beilage") and a
profile & account-lifecycle system: an own-profile Meldebogen with a
Kiez-Chronik tenure timeline, a printable QR-coded Steckbrief card,
public neighbor profiles, self-service email/password change, and a
7-day-undo account deletion that anonymizes into an "Ehemaliges
Mitglied" tombstone while preserving authored content.

Since then the app grew a built-in onboarding walkthrough, Die
Führung (seven chapters, 32 stops), and a shared mailer — SMTP, then
Resend, then a dev-log fallback — that fails closed with a 503 instead
of dropping a message silently. In August the front door changed: the
forum moved to `/forum` behind a login gate, and the root became Das
Schaufenster — a public shop window with a masthead, a heartbeat strip
(air, forum activity, weekend events, today's Kurier) and teasers for
blog, Kiez-Daten and headlines, each linking out to its source rather
than into a login wall. Members are redirected before render and
never see it. Every number on it comes from a real source at runtime,
and a lifeless row is omitted server-side rather than shown as zero —
no invented issue number either, "a fake metric in newspaper's
clothing".

## Architecture

Multilingual AI moderation (TR/EN/DE + leetspeak filters) gates all
user content, backed by a 3-strike ban system that drops banned
sessions to read-only. The kiosk redesign — paper-warm surfaces, ink
borders, carved-italic titles — is now complete across all eleven
surfaces, landing to blog. BLUME air-quality readings and Schillerkiez
demographics still come from public APIs, and the marketplace runs a
13-category taxonomy with draft/publish, a 21-day visibility window,
and buyer↔seller contact relayed so neither side sees an email
address.

Die Führung's spotlight is one oversized box-shadow on a small div
sized to the anchor's rect — stacking-context-proof. The fix that
mattered when the tour grew to seven chapters was anchor lookup:
responsive layouts mount the same control twice, one hidden, and the
first DOM match is often the hidden one; the engine now takes the
first match with real dimensions.

The notification center exists because members learned about replies
by stumbling over them, and about moderation decisions not at all — a
post simply disappeared. Four events now fan out on write into a
`notifications` collection: comments, every moderation decision
including clean approvals and the strike number, official broadcasts,
marketplace inquiries. Actor names are never stored, only ids joined
at read time, so a deleted account reads "Ehemaliges Mitglied"
retroactively; copy renders from i18n keys, so the language toggle
works on old items too. A Mongo TTL index expires everything after 90
days; the bell polls an indexed count every 90 seconds while the tab
is visible — no held-open connections on serverless for neighbourhood
volume. Web push rides on top as best-effort garnish, through a
push-only service worker that must never gain a `fetch` handler, and
the subscribe endpoint accepts only `https` URLs on a push-service
allowlist — otherwise a member could aim a signed POST at any host
they liked.

## Reflection

Built with a manifesto attached — `MANIFESTO.md` sits at the repo's
root as its moral charter, paired with a PolyForm Noncommercial
license and a Field-of-Use Rider: open to nonprofits and public
institutions, closed to political parties, for-profit deployment,
resident surveillance, resale — and to a single person running a copy
as both deployer and sole moderator. The manifesto sets a floor under
whoever runs it: a governance body of three or more, a public
moderation log, transparent funding, an exit clause.

Neither of this year's worst failures announced itself. OpenAI's
credits ran out: the news cron kept returning 200 while saving
nothing, and every submission needing moderation got waved into the
manual review queue instead of erroring. Four days passed with no
monitoring event, because both paths were caught, logged and handled
gracefully. Then the domain move killed a GitHub Actions cron that had
been ringing the air-quality logger every half hour — two days of
writing nothing, recorded nowhere, because a redirect is served at the
edge and no application code ever runs. The watchdog that catches that
one now rides a platform-native cron, since a watchdog sharing its
victim's failure mode is worthless. A cron that returns 200 is not a
cron that worked.

The landing release added a lesson about reviews. The login gate's
`?redirect=` guard checked characters — starts with `/`, not `//`,
not `/\` — and it sat in the plan's own code, reviewed twice. The
URL parser strips tabs before resolving, so `/%09/evil.com` passes
every check and lands off-site: a post-login phishing vector on a
platform that asks neighbours to trust it. The fix parses the
candidate against a fixed base origin and returns the parsed path —
one dependency-free helper shared by middleware and client, replacing
two hand-rolled guards that had already drifted apart. Character
enumeration feels rigorous; it never is.
