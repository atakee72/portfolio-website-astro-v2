## Problem

The Schillerkiez (Berlin Neukölln) needed a digital commons — forum,
calendar, marketplace, local news, air-quality data — without surrendering
to a global platform.

## Build

Astro SSR + React + Svelte islands, MongoDB direct driver, auth-astro
with JWT, TanStack Query with 24h localStorage persistence. Forum,
calendar, marketplace, newsboard with daily fetch, recommendations,
reports & admin moderation.

## Architecture

Multilingual AI moderation (TR/EN/DE + leetspeak filters) gates all
user-generated content before it lands. Carved-title accents per page,
dark-glass design system, BLUME air-quality proxy and Schillerkiez
demographics surfaced from public APIs.

## Reflection

Built with a manifesto attached — the project's moral charter sits at
the root of the repo as `MANIFESTO.md`.
