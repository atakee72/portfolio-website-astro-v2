## Problem

Local audio files deserve a player that respects them: no upload, no
account, no telemetry. Drop a folder, hear your music, see the tags and
cover art the files already carry.

## Build

Vite + React 18 + TypeScript with a custom Tailwind "AFTERGLOW" token
theme (self-hosted Fraunces / Inter / Geist Mono). `music-metadata`
parses ID3 / Vorbis / FLAC; a Web Audio `AnalyserNode` drives a live
frequency visualizer. Library persistence splits by capability —
Chromium uses the File System Access API (zero duplication), Firefox
and Safari store bytes in IndexedDB.

## Architecture

OS-level integration via the Media Session API (lock-screen artwork,
Bluetooth keys, macOS Now Playing, Windows SMTC, Linux MPRIS). A
**VibeOrb** lifts the current track's dominant colour into the
background. Keyboard-first: `Space` play/pause, `←`/`→` seek, `/`
search, `Esc` close. Motion respects `prefers-reduced-motion` end-to-end.

## Reflection

The whole point is that nothing leaves the machine. Designing storage
around three different browser capabilities (rather than picking one
and shimming the others) kept the privacy contract honest.
